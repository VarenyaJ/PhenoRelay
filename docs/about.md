# About

PhenoRelay is not a strict Beacon implementation. Beacon and bycon provide design
direction, especially around capabilities, filters, federation, and response
granularity, but PhenoRelay can deviate when a Phenopacket-native shape is clearer
or safer.

The source data remains GA4GH Phenopacket JSON at the originating site. Any local
database is a rebuildable search index, not the system of record.
