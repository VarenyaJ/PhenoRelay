# Reference Caches

Reference caches store fetched reference metadata and text so evidence validation
is repeatable.

Initial rules:

- cache files are generated by explicit commands;
- cache frontmatter must be parseable and match the expected reference ID;
- snippets must quote the fetched content when validation supports the reference
  source;
- generated cache files must be reviewed before staging;
- network-backed fetches should run in CI or explicit local commands, never on
  package import.
