# Use Cases

PhenoRelay targets institutions and researchers that already hold Phenopacket
collections and want controlled discovery without turning the source collection
into a central database.

Initial use cases:

- search local Phenopacket releases by HPO phenotype, disease, gene, or medical
  action;
- answer existence and count queries without exposing records;
- advertise which query features a site can evaluate;
- attach evidence and reference validation to query examples and curated
  interpretation notes;
- compare local behavior with Beacon-style systems without requiring strict
  Beacon compatibility.
